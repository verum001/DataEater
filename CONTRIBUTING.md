# Contributing

Use issues for reproducible bugs and feature proposals. Include the app version,
Android/device information, steps, expected behavior and a minimal invented fixture.
Keep personal documents, chats and keys out of reports.

Build and run the relevant checks in [development](docs/DEVELOPMENT.md). Explain
what changed, why and which checks passed in a pull request. Preserve compatible
database formats and page references. Use matched evidence for retrieval/model
accuracy claims and describe limits of hardware coverage.

Contributions to original source and documentation are under Apache-2.0 unless
explicitly agreed otherwise. Retain applicable third-party notices. The independent
Linux builder is maintained in [DataEater-builder](https://github.com/verum001/DataEater-builder).
