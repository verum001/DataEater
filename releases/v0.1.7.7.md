# DataEater 0.1.7.7

Database creation now produces offline preparation-quality reports: omitted or sparse pages, oversized passages, unverified PDF layout, and changes to numbers, units, identifiers, restrictions and numbered procedure steps after manual optimisation. Save quality report exports a report bound to the completed database fingerprint. Private database reports remain encrypted with source metadata.

No AI or internet connection is required. Reports identify review needs; they do not certify technical accuracy or reconstruct table/column relationships. Existing extraction defaults and database format remain compatible. Database builds use staged verification before replacing a destination.

Includes an Android-specific regex compatibility fix verified on vivo V2453A / Android 16. Validation: 343 JVM tests, 5 automated real-phone tests, manual PDF picker/database creation/report-save check, Android/Python compatibility checks and lint with zero errors. Existing chats and stored keys preserved.

Android version code 21. Uses the existing release signing certificate. Source is Apache-2.0; dependencies and separately downloaded models retain their own licences. F-Droid inclusion remains pending.
