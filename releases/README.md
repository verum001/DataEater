# Download and install

Download the APK and accompanying notices from the [DataEater releases](https://github.com/verum001/DataEater/releases).
The current prepared version is **v1.2.0**.

Open the APK on Android and allow installation when asked. Install updates over
the existing app to retain chats. The app needs a supported 64-bit Android 8.0+
device; encrypted databases require Android 12+. Download a model in the app and
add a `.dataeater` database for document questions.

See [recommended models](../README.md#recommended-models),
[device-specific benchmarks](../docs/benchmarks.md) and
[publication steps](../docs/release-guide.md).
