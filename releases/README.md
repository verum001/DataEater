# Download and install

Download the APK and accompanying notices from the [DataEater releases](https://github.com/verum001/DataEater/releases).
The latest published version is **v1.4.2**. Versions 1.4.0–1.4.2 were published on 9 October 2026 (Europe/Moscow).

| Version | Main change | Release notes |
|---|---|---|
| 1.4.2 | Confirmed conversation deletion | [Notes](v1.4.2/RELEASE_NOTES.md) · [Download](https://github.com/verum001/DataEater/releases/tag/v1.4.2) |
| 1.4.1 | Local-model input-overflow recovery | [Notes](v1.4.1/RELEASE_NOTES.md) · [Download](https://github.com/verum001/DataEater/releases/tag/v1.4.1) |
| 1.4.0 | Android database builder | [Notes](v1.4.0/RELEASE_NOTES.md) · [Download](https://github.com/verum001/DataEater/releases/tag/v1.4.0) |
| 1.3.1 | Reply length and database strictness | [Published release](https://github.com/verum001/DataEater/releases/tag/v1.3.1) |
| 1.3.0 | Optional OpenRouter AI | [Published release](https://github.com/verum001/DataEater/releases/tag/v1.3.0) |
| 1.2.0 | Conversation memory and model updates | [Published release](https://github.com/verum001/DataEater/releases/tag/v1.2) |

Open the APK on Android and allow installation when asked. Install updates over
the existing app to retain chats. The app needs a supported 64-bit Android 8.0+
device; encrypted database unlocking requires Android 13+. Download a local model or configure optional OpenRouter AI, then add a `.dataeater` database for document questions. Version 1.4.0 and newer can create databases on the phone without a model or network connection.

See [recommended models](../README.md#recommended-models),
[device-specific benchmarks](../docs/benchmarks.md) and
[publication steps](../docs/release-guide.md).
