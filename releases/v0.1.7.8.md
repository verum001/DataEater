# DataEater 0.1.7.8

Database creation can now recognise scanned PDF pages offline in English, Russian or both. Enable Read scanned PDFs (OCR) before creating a database or preparing an optimisation ZIP. No AI model, account or internet is required for OCR. Existing selectable text is preserved; quality reports record OCR language, confidence and whether recognised text was used. Review technical values, warnings and reading order against the original.

Includes accumulated stable interface improvements: long-press session pin/rename/delete menus, dedicated model and database settings screens, and consistent compact buttons. Existing database format, licensing, chats and stored keys remain compatible. Modules and the folder sorter stay in DataEater Beta.

Android version code22. Uses the existing release signing certificate. Tesseract, Leptonica and wrapper libraries are built from pinned source; English/Russian OCR language data is bundled with licences. Android source is Apache-2.0; third-party components and downloaded AI models retain their own terms. F-Droid inclusion remains pending.
