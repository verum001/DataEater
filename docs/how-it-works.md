# How it works for a user

1. Install DataEater and grant the requested storage access.
2. Tap **Download AI**, choose a model and wait for installation. Use a model that fits your device.
3. Copy a compatible database into the DataEater folder on your phone and select it in Settings.
4. Turn **Database on** and ask a question about those documents.
5. Read the answer and expand its source references to check the relevant manual information.

The app refuses to answer from model knowledge when no matching database information is found. When matching text exists, the model can still misunderstand it; verify the cited source before performing work.

Turn **Database off** for general chat. Those answers use the model's knowledge and are not checked against your documents. Long-press a message to select and copy text. Swipe from the left edge to open conversations and Help.

Database downloads are planned for a later release; this preview does not offer an online database catalog. Do not share databases derived from manuals unless you have the necessary rights.
