# Architecture overview

DataEater processes local databases and uses either on-device LiteRT-LM or
explicitly selected OpenRouter inference. Read the complete [architecture and
source map](ARCHITECTURE.md), [database format](DATABASE_FORMAT.md), [Android
builder](ANDROID_BUILDER.md) and [encryption design](ENCRYPTION_DESIGN.md).
Original implementation is published in `app/src/main` under Apache-2.0.
