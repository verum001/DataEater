# AI instructions

## GitHub updates require permission

- You may inspect the project, edit local files, and run local checks as requested.
- Before uploading project changes to GitHub, obtain the user's explicit permission for the specific update. Permission to make local edits does not authorize publishing them.
- This rule applies to git pushes, direct GitHub file or branch updates, pull request creation or updates, merges, and releases.
- Before requesting permission, prepare the local changes and summarize what will be uploaded and the relevant validation results.
- Once the user authorizes a specific update, carry it out without asking again unless its scope materially changes.
- Do not enable automatic pushes or background uploads without explicit user permission.
- Read-only GitHub access, fetching, and pulling updates do not require publishing permission.
